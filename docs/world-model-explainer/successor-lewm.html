METHOD SPECIFICATION / REWARD-FREE EXPLICIT WORLD MODEL

Reward-Free Successor LeWM

一个有限时域、动作条件的 world model：它既预测候选动作序列会到达的 latent，也预测这段未来的累计任务特征。goal value 只是累计特征对 goal 的线性读出，不是另一套独立的 scalar head。

核心对象
\[ \hat S_h(h_t,A_{1:h}) \approx \mathbb E_P\!\left[ \sum_{j=1}^{h}\gamma^{j-1}\psi(s_{t+j}) \middle|h_t,A_{1:h} \right], \qquad \hat C_h(A_{1:h},g) = 1-\frac{\hat S_h^\top\psi(g)}{Z_h} \]

01 / MODEL INTERFACE

模型回答的不是“未来会怎样”，而是“这条明确动作前缀的未来会怎样”。

\(o_t\)

时刻 \(t\) 的图像观测。

\(z_t=\phi_\theta(o_t)\)

动力学 latent，服务于状态预测。

\(\psi_t=\operatorname{norm}(q_\eta(z_t))\)

单位归一化的任务特征，服务于 goal 评分。

\(h_t\)

最近 \(m\) 个 latent 与历史动作构成的 LeWM 状态。

\(A_{1:K}\)

CEM 提供的 \(K\) 步候选动作前缀，不由模型生成。

\(g\)

目标观测，目标向量为 \(\psi_g=\psi(g)\)。

模型输入与输出

\[ h_t = \left(z_{t-m+1:t},a_{t-m+1:t-1}\right), \qquad \left(\hat z_{t+1:t+K},\hat S_{1:K}\right) =F_\omega(h_t,A_{1:K}) \]

输出有两部分。第一部分是逐时刻 latent rollout；第二部分是每个 horizon 的累计 future feature。二者都以同一条动作前缀为条件。

Fω: (B, history, action1:K) → [(B, K, dz), (B, K, dψ)]
STATE PATH ot-m+1:t → φθ → ht
ACTION PATH A1:K → Uξ → uA
SHARED PREFIX TRUNK (ht, uA) → fω
LATENT HEAD Dz(fω) → ẑt+1:t+K
SUCCESSOR HEAD DS(fω) → Ŝ1:K

实现上，\(\hat\psi_{t+j}=\operatorname{norm}(q_\eta(\hat z_{t+j}))\)。因此 latent head 和 successor head 有明确的重叠区域，可以被同 horizon 的 consistency loss 校准。

02 / THEORY

用一个向量 \(S_h\)，同时表达多步 latent 结构与任意目标的有限时域 value。

模型要逼近的条件期望

\[ S_h^\star(h_t,A_{1:h}) = \mathbb E_P\!\left[ \sum_{j=1}^{h} \gamma^{j-1}\psi(s_{t+j}) \ \middle|\ h_t,A_{1:h} \right], \qquad Z_h=\sum_{j=1}^{h}\gamma^{j-1} \]

\(S_h^\star\) 是给定当前历史和候选动作前缀后的 future feature 条件期望。它是一个向量，不绑定某一个具体 goal。

单条离线轨迹上的精确递推

\[ Y_1=\bar\psi_{t+1}, \qquad Y_h=Y_{h-1}+\gamma^{h-1}\bar\psi_{t+h} \]

所以 \(Y_1,\ldots,Y_K\) 是同一条动作前缀的 horizon ladder。MSE 训练 \(\hat S_h\) 去逼近其条件期望，而不是为 \(K\) 个不同 goal 做 scalar 预测。

单位归一化的目标距离

\[ \frac{1}{2}\lVert\psi(s)-\psi(g)\rVert_2^2 = 1-\psi(s)^\top\psi(g) \]
⇒

同 horizon 的有限时域 goal cost

\[ C_h(A_{1:h},g) = \frac{1}{Z_h} \sum_{j=1}^{h} \gamma^{j-1} \frac{1}{2}\lVert\psi(s_{t+j})-\psi(g)\rVert_2^2 = 1-\frac{S_h^\top\psi(g)}{Z_h} \]
语义边界： \(S_h(h_t,A_{1:h})\) 是 action-conditioned finite-horizon plan feature，不是没有动作条件的 \(V_h(h_t,g)\)。这一点让离线训练和 CEM 查询问的是同一个问题。

03 / TRAINING OBJECTIVE

所有监督都来自同一段离线轨迹，不需要 reward 或 goal-specific scalar 标签。

EMA target

\[ \bar z_{t+j}=\phi^{-}(o_{t+j}), \qquad \bar\psi_{t+j}=\operatorname{norm}\left(q^{-}(\bar z_{t+j})\right), \qquad Y_h=\sum_{j=1}^{h}\gamma^{j-1}\bar\psi_{t+j} \]

上标 \((-)\) 表示 EMA target network，所有 target 都 stop-gradient。一个长度至少为 \(m+K\) 的离线片段即可同时产生 \(K\) 个 horizon 的监督。

L1

Multi-step latent

\[\mathcal L_{\mathrm{latent}}=\frac{1}{K}\sum_{h=1}^{K}\left\lVert\hat z_{t+h}-\bar z_{t+h}\right\rVert_2^2\]

锚定每一个未来状态，防止模型只学累计量却丢掉真实的反事实 rollout。

L2

Direct successor

\[\mathcal L_{\mathrm{SF}}=\frac{1}{K}\sum_{h=1}^{K}\left\lVert\hat S_h-Y_h\right\rVert_2^2\]

给长期累计特征一个直接、真实的多时域监督，而不是仅靠 rollout 间接求和。

L3

Overlap consistency

\[\mathcal L_{\mathrm{overlap}}=\frac{1}{K}\sum_{h=1}^{K}\left\lVert\hat S_h-\operatorname{sg}\!\left[\sum_{j=1}^{h}\gamma^{j-1}\hat\psi_{t+j}\right]\right\rVert_2^2\]

让 successor head 对齐 latent rollout 的累计。初版只让梯度流向 \(\hat S\)；latent head 已由 L1 直接锚定，避免 consistency 自己制造移动目标。

完整目标

\[ \mathcal L = \mathcal L_{\mathrm{SIGReg}} + \lambda_z\mathcal L_{\mathrm{latent}} + \lambda_S\mathcal L_{\mathrm{SF}} + \lambda_C\mathcal L_{\mathrm{overlap}} \]

04 / IMPLEMENTATION SKETCH

训练代码里，关键是先构造全部 \(K\) 个真实 successor target，再让两个 head 交叉校准。

PyTorch 训练核心

def successor_loss(
    batch, model, target_model, gamma, horizon
):
    history = make_history(
        batch.obs, batch.actions
    )
    action_prefix = batch.actions[:, :horizon]

    z_hat, s_hat = model(
        history, action_prefix
    )
    with torch.no_grad():
        z_target = target_model.encode(
            batch.future_obs[:, :horizon]
        )
        psi_target = normalize(
            target_model.project(z_target)
        )

    discount = gamma ** torch.arange(
        horizon, device=z_hat.device
    )
    y = torch.cumsum(
        discount[None, :, None] * psi_target,
        dim=1,
    )

    latent = F.mse_loss(z_hat, z_target)
    successor = F.mse_loss(s_hat, y)

    psi_hat = normalize(
        model.project(z_hat)
    )
    rollout_sum = torch.cumsum(
        discount[None, :, None] * psi_hat,
        dim=1,
    )
    overlap = F.mse_loss(
        s_hat, rollout_sum.detach()
    )

    return latent, successor, overlap

CEM cost 接口

def candidate_cost(
    history,
    candidate_actions,
    goal_obs,
    gamma,
):
    # candidate_actions: (N, K, action_dim)
    # history and goal are broadcast to N.
    _, s_hat = model(
        history, candidate_actions
    )

    goal_z = model.encode(goal_obs)
    psi_goal = normalize(
        model.project(goal_z)
    )
    horizon = candidate_actions.shape[1]
    discount = gamma ** torch.arange(
        horizon, device=s_hat.device
    )
    z_k = discount.sum()
    score = (
        s_hat[:, -1] * psi_goal
    ).sum(dim=-1) / z_k

    # All horizon costs are included.
    return 1.0 - score
输出 shape\(\hat z:(B,K,d_z)\)，\(\hat S:(B,K,d_\psi)\)。当前实现的 `(B,16)` 若代表 16 个不同 future goals，不是本方案要的 horizon ladder。
规划规则CEM 给完整 \(K\) 步动作并直接最小化 \(\hat C_K\)。不要再加一个相同 horizon 的 terminal latent distance，否则会 double count。
训练顺序先跑 \(\lambda_C=0\) 的 latent + direct successor 版本；确认二者预测质量后，再逐步打开 overlap consistency。

05 / INVARIANTS AND LIMITS

这套方案成立的前提，以及它明确不解决什么。

01

无 hidden continuation policy

如果 score 的 horizon 是 \(K\)，CEM 必须提供 \(K\) 个动作。想估计更远未来，就增加 action prefix 或显式引入 policy；没有第三种免费语义。

02

Value 是读出，不是新模型

goal 只在规划时通过 \(\psi_g\) 进入点积。训练 \(S_h\) 时不需要采样 goal，不需要为每一个 future goal 拟合 scalar MC target。

03

OOD 仍是核心风险

CEM 会偏好模型低估 cost 的动作前缀。评测必须单独报告候选排名、不同 horizon 的 latent error 和真实环境成功率。

最终一句话： 模型学习的是“候选动作前缀对应的未来特征序列”；目标 value 只是从这个通用向量表示中读取出来。
