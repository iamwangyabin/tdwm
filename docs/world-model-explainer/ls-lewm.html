01 / PROBLEM SETUP

先把任务说清楚：它到底在预测什么？

每一条公式都来自一个具体需要。先从机器人看到什么、能做什么、想去哪里开始。

A

观测

机器人在时间 (t) 看到一张图片，记作 (o_t)。它不是环境完整状态，只是当前能看到的信息。

\(o_t = \text{当前图片}\)
B

动作

机器人选择动作 (a_t)，例如向左推、向右推或改变末端执行器的方向。

\(a_t = \text{当前要执行的动作}\)
C

目标

目标也可以由一张图片给出，记作 (o_g)。模型会把它变成目标 latent (z_g)。

\(o_g \xrightarrow{\phi} z_g\)
前因

像素太大、太细，而且无法直接告诉模型“什么变化对控制最重要”。

↓
后果

先用 encoder 把图片压缩成控制用的 latent 表示。

第一个桥梁图片 → latent
\[ z_t = \phi(o_t) \]

\(\phi\) 是 encoder。它的目标不是生成一个人能读懂的坐标系，而是学习一个对预测和控制有用的内部表示。

02 / LOCAL DYNAMICS

为什么要记住历史？

同一张图片下，物体可能正在向左运动，也可能正在向右运动。当前画面不一定包含足够的速度信息。

过去\(z_{t-2}\)\(z_{t-1}\)\(z_t\)现在
\(a_{t-2}\)\(a_{t-1}\)当前动作还没执行

历史动作告诉模型“我是怎么来到现在的”。这就是为什么 LeWM 的输入不是一个 latent，而是一段 history。

历史上下文LeWM 的状态
\[ h_t = \left(z_{t-m+1:t},\ a_{t-m+1:t-1}\right), \qquad z_t = \phi(o_t) \]

当前配置 (m=3)，所以大致是最近三个 latent 加上最近两个历史动作。

前因

模型需要知道当前动作会把系统推向哪里。

→
公式

输入 history 和当前动作，预测下一步 latent。

局部 world model任意候选动作都可以问
\[ \hat z_{t+1} = F(h_t, a_t) \]

这条公式让 CEM 可以问模型：“如果我现在执行这个动作，下一步大概会到哪里？”

03 / GOAL DISTANCE

没有奖励时，怎么定义“做得好”？

当前方法使用 goal-reaching 代价：latent 离目标越近，代价越低。这里的“低”就是好。

目标代价cost 越小越好
\[ c(z,z_g) = \frac{\lVert z-z_g\rVert_2^2}{D} \]
\(z\) 当前状态的 latent \(z_g\) 目标状态的 latent \(D\) latent 维度，当前为 192

一个小例子

把公式变成数字

如果 (z=[1,2])，目标 (z_g=[3,5])，并且 (D=2)：

\[ c(z,z_g) = \frac{(1-3)^2+(2-5)^2}{2} = \frac{4+9}{2}=6.5 \]

如果机器人后来走到更接近目标的 latent，6.5 就会变小。

为什么不直接比较图片？ 像素距离容易被背景、光照和纹理影响。方法假设 encoder 学出的 latent 距离更接近控制任务真正关心的差异。

04 / CONTINUATION POLICY

长期动作从哪里来？

如果让 LeWM 永远递归预测，误差会累积。于是方法另外学习一个“给定目标，下一步怎么走”的策略。

\(z_0\)\(a_0\)\(z_1\)\(a_1\)\(z_2\)\(a_2\)\(z_3\)

在离线轨迹中，未来状态可以事后充当目标。例如把 (z_2) 当作目标，就可以用真实动作 (a_0) 监督当前策略。

当前\(z_0\)目标\(z_2\)标签动作\(a_0\)
目标条件策略policy 不是 world model
\[ \pi_\eta(h_t,z_g) \approx a_t \]

它学习的是“数据中通常如何朝未来目标走”，不是通过强化学习算出来的全局最优动作。

为什么需要它

successor 需要知道长期应该按照什么行为继续。

→
它提供什么

一个可执行、尽量接近离线数据分布的 continuation policy。

05 / SUCCESSOR FEATURES

为什么 successor 输出一个向量，而不是一个数字？

目标会变化。向量先总结“未来会访问什么”，目标权重再把它转换成“对这个目标有多远”。

A

先把状态展开成 feature

\[ \chi(z)=\left[\frac{z}{\sqrt D},\ \frac{\lVert z\rVert_2^2}{D},\ 1\right] \]

保留三类信息：latent 本身、latent 的平方大小、以及常数项。

B

目标生成一组权重

\[ w(z_g)=\left[-\frac{2z_g}{\sqrt D},\ 1,\ \frac{\lVert z_g\rVert_2^2}{D}\right] \]

换一个目标，只需要换 (w(z_g))，不需要重新训练一个独立的 value 网络。

代数检查为什么两者点乘正好是距离？
\[ \begin{aligned} w(z_g)^\top\chi(z) &= \left(-\frac{2z_g}{\sqrt D}\right)^\top\left(\frac{z}{\sqrt D}\right) + \frac{\lVert z\rVert_2^2}{D} + \frac{\lVert z_g\rVert_2^2}{D} \\ &= -\frac{2z_g^\top z}{D} + \frac{\lVert z\rVert_2^2}{D} + \frac{\lVert z_g\rVert_2^2}{D} \\ &= \frac{\lVert z-z_g\rVert_2^2}{D} \end{aligned} \]

最后一步只是平方展开式：(lVert z-z_g Vert^2=lVert z Vert^2-2z_g^ op z+lVert z_g Vert^2)。所以这里不是经验近似，而是严格的代数恒等式。

重要直觉 successor 不直接回答“离某一个固定目标多远”，而是预测未来 feature 的累计；真正面对哪个目标，再用 (w(z_g)) 读出对应的距离。

06 / THE LONG-TERM OBJECT

Successor 本身到底在预测什么？

把“未来很多步的目标距离”拆成“未来很多步的 feature 访问记录”。

向量 successor当前动作之后交给目标策略
\[ G^{\pi_g}(h_t,a_t,z_g) =(1-\gamma)\,\mathbb{E}\!\left[ \sum_{k=0}^{\tau_g-t-1}\gamma^k\,\chi(z_{t+k+1}) \ \middle|\ h_t,a_t,\pi_g \right] \]
\(G\)未来 feature 的折扣累计，当前为 (D+2=194) 维向量。
\(k=0\)当前动作执行后的第一个状态是 (z_{t+1})，所以从 (t+1) 开始。
\(\gamma^k\)未来越远，权重越小。当前配置是 (gamma=0.95)。
\(\tau_g\)到达目标或 episode 终止的时间，终止后不再继续累加。
\(\mathbb{E}\)如果未来有随机性，预测的是按照策略执行后的平均结果。
把向量读成目标代价
\[ w(z_g)^\top G^{\pi_g}(h_t,a_t,z_g) = \text{未来折扣目标距离} \]

07 / BELLMAN RECURSION

为什么训练时可以只看一步？

因为“未来总和”可以拆成“下一步 + 从下一步开始的剩余总和”。这就是 Bellman 递推。

一阶 TD 目标online 学，EMA target 提供目标
\[ \begin{aligned} G(h_t,a_t,z_g) &= (1-\gamma)\chi(z_{t+1}) \\ &\quad + \gamma(1-d_{t+1})\, G_{\mathrm{ema}}\!\left( h_{t+1},\pi_{\mathrm{ema}}(h_{t+1},z_g),z_g \right) \end{aligned} \]

第一项：马上到达的下一状态 (z_{t+1}) 带来即时 feature。

第二项：从下一状态开始，按目标策略继续走的剩余结果。

终止标记：如果 (d_{t+1}=1)，剩余项被乘成 0，不再 bootstrap。

展开：为什么要用 EMA target？

如果 online 网络既负责预测 (G)，又负责生成训练目标，那么它会一边追逐自己一边改变目标，训练容易抖动。于是保存一个变化较慢的 EMA 副本：

\[ \theta_{\mathrm{target}} \leftarrow \rho\,\theta_{\mathrm{target}} +(1-\rho)\,\theta_{\mathrm{online}} \]

当前配置 ( ho=0.995)。target 网络不通过这次 TD loss 反向传播，只负责提供相对稳定的参照。

08 / TRAINING OBJECTIVE

这些损失函数分别在教模型什么？

LS-LeWM 不是只训练一个 head，而是让局部 world model、successor 和 continuation policy 共同工作。

联合目标每一项都有不同职责
\[ \mathcal{L} = \mathcal{L}_{\mathrm{local}} + \beta\mathcal{L}_{\mathrm{SIGReg}} + \lambda_G\left( \mathcal{L}_{\mathrm{TD}} +\lambda_b\mathcal{L}_{\mathrm{terminal}} \right) +\lambda_\pi\mathcal{L}_{\mathrm{BC}} \]
\(\mathcal{L}_{\mathrm{local}}\)

局部预测

让 LeWM 的 (hat z_{t+1}) 接近真实 (z_{t+1})，保住短期动力学能力。

\(\mathcal{L}_{\mathrm{SIGReg}}\)

latent 正则

沿用 LeWM 的表示约束，减少 latent 表示退化或塌缩。

\(\mathcal{L}_{\mathrm{TD}}\)

successor 递推

让 online successor 接近 Bellman 目标，学会累计未来 feature。

\(\mathcal{L}_{\mathrm{BC}}\)

策略模仿

让 (pi_eta(h_t,z_g)) 学习离线轨迹里的真实动作。

\(\mathcal{L}_{\mathrm{terminal}}\)

目标边界

在已经到达目标的上下文里，要求 successor 接近零。

为什么训练序列是 19？

history=3 时，最长可以看到 offset=16

序列 (z_0,ldots,z_{18}) 中，第一段完整 history 从 (z_2) 开始。于是最远目标是 (z_{18})，offset 是 (18-2=16)。

\(z_0\)\(z_1\)\(z_2\)\(z_3\)\(z_4\)⋯\(z_{18}\)
historycurrentoffset=1offset=2⋯offset=16
展开：为什么要 uniform offset weighting？

offset=1 的训练 pair 最多，offset 越远，能构造的 pair 越少。如果把所有 pair 混合平均，短距离目标会淹没长距离目标。uniform offset weighting 的做法是先分别平均每个 offset 的 loss，再平均这些 offset。

09 / MPC INFERENCE

最后回到规划：CEM 如何组合 prefix 和 tail？

CEM 不需要知道 successor 的内部实现，只需要给它候选动作序列的最终代价。

输入当前 history
+ 目标 (z_g)
→
候选 prefix(a_t,ldots,a_{t+H-1})
→
LeWM预测 (H) 步 latent
→
Successor估计长期 tail
LS-LeWM 的 MPC costprefix 和 tail 不重叠
\[ \begin{aligned} J_H &=(1-\gamma)\sum_{k=1}^{H}\gamma^{k-1} \frac{\lVert\hat z_{t+k}-z_g\rVert_2^2}{D} \\ &\quad+\gamma^H\, w(z_g)^\top G\!\left( \hat h_{t+H}, \pi(\hat h_{t+H},z_g), z_g \right) \end{aligned} \]
第一行 CEM 候选动作造成的短期显式路径代价。 第二行 prefix 结束后，按 policy 继续执行的长期估计。
1采样很多候选动作序列
2用上式计算每条序列的 (J_H)
3保留 cost 最小的 elite
4更新动作分布并重复
5只执行第一步，然后重新规划
当前配置的尺度\(H=5,\quad \gamma=0.95\)

五步 prefix 之后的 tail 权重是 (gamma^5\approx0.774)。所以 tail 不是装饰，它承担了相当一部分长期判断。

10 / WHAT TO CHECK

公式闭合，不等于实验已经证明有效

数学告诉我们这个方法想表达什么；实验还要检查它是否在真实的模型误差、数据分布和终止语义下成立。

01

终止语义

训练中到达目标后停止 bootstrap，规划中的 prefix 是否也在同一个时刻停止累计，需要保持一致。

02

history 对齐

successor 训练使用的历史长度和评估时 padding 出来的历史是否分布一致。

03

imagined latent

训练时大量使用真实 latent，推理 tail 接收 LeWM 预测 latent，二者的差异需要通过 smoke 和消融实验量化。

04

公平消融

至少比较原始 LeWM、dense prefix、successor tail、policy warm start 和完整 LS-LeWM，才能知道提升来自哪里。

ONE SENTENCE TO KEEP
