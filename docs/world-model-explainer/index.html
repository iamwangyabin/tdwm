TDWM RESEARCH BRIEF

让世界模型不只会预测，
还真正有利于规划

我们研究的是一个很具体的问题：从离线视觉轨迹学到的 latent world model，能否既保留通用、任意动作的短期动力学，又学会长期可达性和任务相关结构，从而在真实模拟环境里做出更好的动作选择。

一句话抓住任务

模型在脑中想象，环境在现实中裁判。

数据集不是一部必须照着播放的录像。它提供训练经验，也可以提供固定、可复现的起点和目标。评测开始后，智能体仍然可以自由行动。

世界模型只负责预测候选动作可能造成的未来；Pymunk、MuJoCo 或二维碰撞环境真正执行动作，并决定成功还是失败。

METHOD TRADE-OFFS

三条核心路线到底在改什么

它们不只是三个模型名字，而是对“什么样的 latent 才对控制有用”的三种不同回答。

局部、动作条件世界模型

LeWM：先学会预测下一段 latent

从像素编码当前状态，根据任意候选动作预测未来 latent，再用 latent 距离作为目标代价，让 CEM 搜索动作序列。

图像→Encoder→Latent+Action→Predictor→未来 latent

优势

  • reward-free，训练数据无需任务奖励
  • 能比较任意候选 primitive action
  • 结构简单，适合做干净、可审计的基线

局限

  • 一步预测准，不保证多步规划准
  • latent L2 可能不等于真实可达距离
  • 开放环滚动会累积误差

WHAT CAN TDWM CONTRIBUTE?

我们讨论过的研究思路，应该怎样收窄

宽泛地说“用 RL 帮助世界模型”不够新，也不可证伪。更可信的研究问题要明确梯度进哪里、保留什么能力、怎样排除替代解释。

01

冻结 LeWM，先做长期诊断头

在不改变底座的情况下学习多 horizon、successor 或 occupancy 预测，检验长期信息是否真的补充了 LeWM。

优点
因果归因最干净；实现风险低
缺点
可能只证明下游头有效，没改善 latent
建议第一步
02

局部动力学 + 长期 occupancy 双层模型

LeWM 保留任意 primitive action 的局部反事实预测，长期分支学习 policy-conditioned future occupancy，并约束两者一致。

优点
最接近仍有空间的科学问题
缺点
接口、训练稳定性和公平匹配更复杂
潜在主线
03

决策相关损失进入 latent

用 value、TD、VAML、bisimulation 或 successor 信号改变表示几何，直接追求“对决策更有用”的 latent。

优点
可能直接提升规划和长时信用分配
缺点
容易任务化，损害 reward-free 复用
高风险路线
04

只改 planner，不动 world model

在冻结模型上增加 terminal value、层级 subgoal、temporal cost 或 uncertainty-aware 规划。

优点
工程收益快；不会破坏预测模型
缺点
不能声称“世界模型学得更好”
必要对照

IDEA EVOLUTION

你的思路怎样一步步收窄

起点

RL 能不能帮助 LeWM？

直觉成立，但范围过大，几乎整个 model-based RL 都能被算进去。

第一次收窄

用 TD 防坍塌、让 latent 更物理

相关工作已经很多，而且“对当前 value 有用”不等于“保留通用物理”。

第二次收窄

给 LeWM 加长期 reachability

RC-aux、Temporal-Distance、Fast-LeWM、TD-JEPA 已覆盖多种版本。

当前可检验问题

局部反事实与长期 occupancy 是否互补？

不是再加一个 loss，而是证明两类 operator 各自提供对方没有的信息，并在联合时不互相破坏。

THE CANDIDATE INTERFACE

候选方案不是“LeWM + TD loss”，而是两个 operator 的受控协作

左边回答任意动作前缀会发生什么，右边回答某类策略在较长 horizon 会占据什么未来。真正的研究变量是二者如何交换信息，以及梯度是否允许进入 encoder。

LOCAL

Primitive local operator

输入当前历史与任意候选动作序列，输出短期 counterfactual latent rollout。

compatibility⇄consistency teacher
diagnostic / arbitration
HORIZON

Policy-conditioned operator

从真实数据学习长期 occupancy、feature expectation 或 horizon-conditioned future。

A. Frozen diagnostic冻结 LeWM，只检验长期误差信号是否能预测规划失败。
B. Detached adapter梯度只进轻量 adapter / dynamics，不碰 encoder 与 SIGReg latent。
C. End-to-end只有 A、B 有明确增益后才开放 encoder，并记录梯度冲突。

CLAIM FILTER

什么证据才能支持“RL 改善了 LeWM”？

  1. 预测没有变差：一步、多步与 OOD rollout 都要报告。
  2. 规划确实变好：同数据、同 CEM 预算、同起点目标和多 seed。
  3. 不是只会当前奖励：冻结迁移到新目标或新奖励仍应保留价值。
  4. 排除简单解释：对比冻结头、普通多步 loss、RC-aux、planner-only 等量基线。

FALSIFICATION FIRST

这项研究最重要的不是证明自己对，而是尽快发现自己哪里错

继续做的信号

  • 长期头对 frozen-LeWM 失败有额外预测力
  • 同 planner、cost、compute 下提升至少两个非饱和任务
  • held-out actions 与 reward revaluation 不退化
  • 多 seed 支持结论

立即停或改题

  • 冻结 LeWM + 普通 head 已获得全部收益
  • multi-horizon、RC-aux 或 Jumpy 已解释增益
  • 只有新 terminal cost 提高成功率
  • 长期提升伴随 action marginalization

THE RESEARCH QUESTION

能否同时保住短期反事实动力学，
又学到真正支持长期决策的结构？

如果只提升成功率却损害通用预测，结论应是“模型被任务化了”；如果长期结构、预测质量、跨目标迁移和公平控制评测同时改善，才有资格说我们得到了更好的世界模型。
